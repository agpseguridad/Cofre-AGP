# Cofre-AGP
Es una aplicacion que respalda usuarios y contraseñas de las personas (Clientes, Familiares, etc). Cada Titular puede almacenar Usuario y Contraseña asiciadas a la aplicacion o pagina que corresponda. Con la posibilidad de poder subir fotos de respaldo por cada uno de los titulares (Clientes, Familiares, etc.)
